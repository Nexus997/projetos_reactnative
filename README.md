# projetos_reactnative
# Meu primeiro projeto React Native

Projeto desenvolvido durante meus estudos de **React Native**, com o objetivo de praticar os principais conceitos de desenvolvimento de aplicativos.

## 🚀 Tecnologias

* React Native
* Expo
* JavaScript
* Node.js

## 📱 Sobre o projeto

Este projeto faz parte do meu processo de aprendizado em React Native. Nele estou praticando criação de componentes, estilização, navegação e interação com o usuário.

## ▶️ Como executar

1. Clone este repositório.
2. Instale as dependências:

```bash
npm install
```

3. Inicie o projeto:

```bash
npx expo start
```

4. Abra o aplicativo utilizando um dispositivo físico, emulador ou Expo Go.

## 📚 Objetivo

Praticar e documentar minha evolução no desenvolvimento de aplicativos utilizando React Native.
